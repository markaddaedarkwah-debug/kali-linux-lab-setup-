📌 Overview

Welcome to my Kali Linux Cybersecurity Lab!

This repository documents my hands-on journey in cybersecurity using Kali Linux. It contains practical exercises, terminal commands, network scanning experiments, security tools, and penetration-testing learning activities.

The main objective is to build practical cybersecurity skills through consistent laboratory exercises.

🎯 Learning Objectives

- Linux fundamentals and system administration.
- Network reconnaissance and information gathering.
- Network scanning using Nmap.
- Packet analysis using Wireshark.
- Web application security testing using Burp Suite.
- Vulnerability assessment.
- Basic penetration testing.
- Python scripting for cybersecurity automation.
